## 🚀 Project Overview

This project analyzes AtliQ Hardware's business performance by solving 10 ad-hoc business requests using SQL. The objective was to demonstrate SQL proficiency while converting analytical findings into actionable business recommendations.

- ✅ Demonstrated end-to-end analytical thinking
